# Prime Tables
A Node.js application that generates a multiplication table using the first N prime numbers.

## How to run

Start the application:
`node src/app.js`

Run the tests:
`node --test`

## What I'm pleased with
The code is separated into clear functions for prime generation, table generation, formatting, and user input. Also the prime algorithm only checks 
divisors up to the square root of the number, which is the logic I had in my head going into this exercise, so I am happy to have made it work efficiently.

## What I would do with more time
With more time I would improve the visual presentation of the application using HTML and CSS, making the interface more intuitive and accessible for new users.
